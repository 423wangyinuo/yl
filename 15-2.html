📚 JavaScript 程序结构

循环结构（for / while / do-while）与条件结构（if-else / switch）

← 返回首页
LOOP 循环结构 —— 让代码重复执行
// for 循环：已知循环次数 for (var yl_i = 1; yl_i <= 5; yl_i++) { console.log("for: " + yl_i); }

运行结果 ↓

// while 循环：条件满足就执行 var yl_count = 3; while (yl_count > 0) { console.log("while: " + yl_count); yl_count--; }

运行结果 ↓

// do-while：先执行一次再判断 var yl_n = 5; do { console.log("do-while: " + yl_n); yl_n--; } while (yl_n > 2);

运行结果 ↓

COND 条件结构 —— 让代码有选择地执行
// if - else if - else var yl_score = 85; if (yl_score >= 90) { console.log("优秀 A"); } else if (yl_score >= 75) { console.log("良好 B"); } else if (yl_score >= 60) { console.log("及格 C"); } else { console.log("不及格 D"); }

运行结果 ↓

// switch：多条件等值判断 var yl_day = 3; switch (yl_day) { case 1: console.log("周一"); break; case 2: console.log("周二"); break; case 3: console.log("周三"); break; default: console.log("其他"); }

运行结果 ↓

MIX 综合：循环 + 条件 —— 1~15 偶数高亮
// for 循环 + if 判断：高亮偶数 for (var yl_i = 1; yl_i <= 15; yl_i++) { if (yl_i % 2 === 0) { console.log("偶数: " + yl_i); } else { console.log("奇数: " + yl_i); } }

运行结果 ↓（黄色=偶数，红色=奇数）

💡 提示：for 适合已知次数，while 适合不确定次数；
多分支条件用 switch 比多个 if-else if 更清晰。
