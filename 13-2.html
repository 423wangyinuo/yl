Exercise 13-2 · Inline SVG

Lucide
SVG 图标实践

用 data-lucide 属性声明图标名称，页面加载后由 lucide.min.js 把每个占位元素替换为真正的内联 SVG，可以直接用 CSS 的 width、height、stroke 等属性控制。

实现方式：内联 SVG（Inline SVG）

本页面引用本地 cdn/lucide/lucide.min.js，占位写法为 <i data-lucide="star"></i>，运行时由 lucide.createIcons() 注入 SVG 节点。

SVG 图标的优势

每个图标都是真实 DOM 节点，可用 CSS 精确控制尺寸、描边、颜色与动画，利于无障碍访问。
