对象字面量 / object literal

{ key: value }
把现实中的“学生”写成 JavaScript 对象
var yl_student = {
  name: "王一诺",
  title: "网页设计学习者",
  age: 20,
  city: "杭州",
  skills: ["HTML", "CSS", "JavaScript"],
  isLearning: true,
  introduce: function () {
    return "你好，我是 " + this.name;
  }
};
运行结果 console.log(yl_student.name) → 王一诺

对象的其他常用操作

遍历枚举、引用复制，以及 JSON 序列化。

遍历与枚举

分别取得对象的键、值、键值对，或用 for...in 逐项访问。

Object.keys(obj) · Object.values(obj)
Object.entries(obj) · for (var key in obj)
点击方法，查看枚举结果。

复制值，还是复制引用？

对象赋值传递的是引用；浅拷贝只复制第一层，嵌套对象仍共享。

var alias = source; // 同一个对象
var copy = { ...source }; // 浅拷贝
原对象与副本等待演示。

序列化与反序列化

JSON.stringify 把数据变成 JSON 字符串；JSON.parse 再还原为新对象。函数属性不会被序列化。

var text = JSON.stringify(obj);
var restored = JSON.parse(text);
点击 stringify 查看 JSON 文本。

对象操作速记

用 Object.hasOwn() 检查自有属性；for...in 可能枚举到原型链上的属性。

"name" in obj · Object.hasOwn(obj, "name")
delete obj.key · Object.assign({}, obj)
记忆：读取用点号 / 方括号；新增和修改用赋值；删除用 delete；遍历用 keys / values / entries。
小结：用点号访问属性：yl_student.name；也可以用方括号：yl_student["city"]。当属性名存放在变量里时，方括号写法尤其方便。对象方法中的 this 指向调用该方法的对象。
每个对象都是一组有关联的数据与行为。
