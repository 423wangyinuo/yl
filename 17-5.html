17-5 / JAVASCRIPT TIMERS

让代码按时运行

用可交互的小实验认识一次性定时器与重复定时器。

← 返回课堂实践首页
⏱

两种定时器：setTimeout() 延迟执行一次；setInterval() 按间隔重复执行。定时器会返回 ID，分别用 clearTimeout() 和 clearInterval() 取消。

一次性定时器

setTimeout

设置延迟时间并启动任务。倒计时结束后回调只执行一次；等待期间可以取消。

var timerId = setTimeout(function () {
  // 延迟后执行一次
}, delay);
剩余时间 — 任务尚未启动

点击“启动一次”开始计时。

取消方法：clearTimeout(timerId)

重复定时器

setInterval

启动后每秒执行一次回调并增加计数。暂停按钮会清除当前 interval。

var timerId = setInterval(function () {
  // 每隔一段时间重复执行
}, interval);
回调执行次数 0 间隔：1 秒

点击“开始计数”启动重复任务。

停止方法：clearInterval(timerId)

setTimeout：稍后做一次

适合延迟提示、稍后执行操作。回调执行后，这个 timeout 就完成了。

setInterval：每隔一段时间做一次

适合周期更新。任务不再需要时及时清除，避免回调持续运行。

定时器的延迟是“至少等待多久”，实际执行时间还会受到浏览器任务队列影响。
