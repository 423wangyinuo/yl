Web 前端长度单位

CSS 中的绝对单位与相对单位

绝对长度单位

px
像素，最常用的屏幕单位。1px 对应屏幕上的一个物理像素点（CSS 像素）。
width: 200px;
pt
点（Point），印刷单位。1pt = 1/72 英寸，常用于打印样式。
font-size: 12pt;
pc
派卡（Pica），印刷单位。1pc = 12pt = 1/6 英寸。
margin: 1pc;
in
英寸（Inch）。1in = 96px = 2.54cm，常用于打印。
width: 2in;
cm
厘米。1cm = 37.8px，常用于打印样式表。
height: 5cm;
mm
毫米。1mm = 1/10 cm，常用于打印样式表。
padding: 10mm;

相对长度单位

em
相对于当前元素的 font-size。若自身未设定，则继承父元素。
font-size: 1.5em;
rem
相对于根元素（html）的 font-size，避免嵌套影响。
font-size: 1.2rem;
%
相对于父元素对应属性的百分比。
width: 80%;
vw
视口宽度的 1%。100vw = 视口总宽度。
width: 50vw;
vh
视口高度的 1%。100vh = 视口总高度。
height: 100vh;
vmin
视口宽度和高度中较小值的 1%。
font-size: 4vmin;
vmax
视口宽度和高度中较大值的 1%。
font-size: 4vmax;
ch
当前字体中 "0" 字符的宽度，常用于限制文本列宽。
max-width: 70ch;
ex
当前字体中 "x" 字符的高度，较少使用。
height: 5ex;

使用建议：屏幕显示优先使用 px、rem、vw/vh；打印样式使用 pt、cm、mm、in。响应式布局中推荐使用 rem 和 vw/vh 替代固定 px，以获得更好的可访问性和适配性。
