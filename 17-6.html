Promise 链：then + Promise.all

买原料()
  .then(取原料)
  .then(function () {
    return Promise.all([
      和面(),
      和馅()
    ]);
  })
  .then(包饺子)
  .then(吃饺子);

每个 then 等前一步完成；Promise.all 等并行任务全部完成。

async / await：更接近顺序阅读

async function 包饺子流程() {
  await 买原料();
  await 取原料();
  await Promise.all([
    和面(),
    和馅()
  ]);
  await 包饺子();
  await 吃饺子();
}

await 等待 Promise；并行任务仍要一起交给 Promise.all。

所有步骤均由 setTimeout 模拟；买原料 6 秒，和面与和馅并行。
